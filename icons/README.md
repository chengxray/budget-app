# Icons

Place your app icons here:
- icon-192.png (192x192)
- icon-512.png (512x512)

You can use the included icon.svg as source, or generate PNG files from any online SVG-to-PNG converter.

The app works without these icons - they are only needed for PWA installation.
Alternatively, open icons/icon.svg in a browser and screenshot to create the PNG files.
